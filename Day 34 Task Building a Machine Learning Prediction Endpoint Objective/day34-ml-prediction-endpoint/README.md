# Day 34 Task - Building a Machine Learning Prediction Endpoint

## Objective

Learn how to integrate a trained Machine Learning model into a FastAPI application
and expose it through a `POST /predict` endpoint that validates input, runs the
model, and returns predictions as JSON.

## Important note about the model

This task asks to load the saved model from Day 30's pipeline. Since that exact
file was not available to include here, this folder includes `train_model.py`,
a small script that trains and saves a model the same way (using `joblib`) so
the whole project runs end to end out of the box. It trains a `RandomForestClassifier`
on the classic iris dataset with 4 numeric features.

**If you already have your own `model.joblib` from Day 30:** just replace the file
in `model/model.joblib`, and update the field names in `main.py` to match the
features your model actually expects.

## Request and Response Models

**PredictionRequest**

| Field         | Type  | Rule                  |
|---------------|-------|--------------------------|
| sepal_length  | float | must be greater than 0  |
| sepal_width   | float | must be greater than 0  |
| petal_length  | float | must be greater than 0  |
| petal_width   | float | must be greater than 0  |

**PredictionResponse**

| Field       | Type   | Description                        |
|-------------|--------|---------------------------------------|
| prediction  | string | Predicted class name                  |
| confidence  | float  | Probability of the predicted class    |

## How to run this project

1. Install the requirements:
```
pip install -r requirements.txt
```

2. Train and save the model (already done once, but you can re-run it anytime):
```
python train_model.py
```

3. Start the API:
```
uvicorn main:app --reload
```

4. Open Swagger docs:
```
http://127.0.0.1:8000/docs
```

## API Usage Example

Request:
```
POST /predict
{
  "sepal_length": 5.1,
  "sepal_width": 3.5,
  "petal_length": 1.4,
  "petal_width": 0.2
}
```

Response:
```
{
  "prediction": "setosa",
  "confidence": 1.0
}
```

Invalid request (negative value):
```
POST /predict
{
  "sepal_length": -1,
  "sepal_width": 3.1,
  "petal_length": 4.7,
  "petal_width": 1.5
}
```
Returns `422 Unprocessable Entity` because `sepal_length` must be greater than 0.

## A note on the screenshots

`train_model.py` was actually run to produce the real `model.joblib` file included
in this folder, and the prediction numbers shown (setosa / versicolor with 1.0
confidence) were generated by actually loading that model and calling `predict`
on it, so those results are genuine, not guessed. The FastAPI server itself was
not available to launch in this environment, so the request/response pairs are
shown as rendered terminal images using those real model outputs rather than a
live browser capture. Running the steps above on your own machine will produce
matching results with the real `/docs` page.
