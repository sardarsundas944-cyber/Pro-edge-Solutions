# Student Performance Calculator

This is a simple beginner-level Python project for Day 2 Python fundamentals.

## What this program does

The program asks for student details:

- Student name
- Student ID
- Department
- Semester

Then it asks for marks in five subjects:

- Mathematics
- Science
- English
- Computer
- History

After that, it calculates:

- Total marks
- Average marks
- Percentage
- Pass or Fail result

## Python basics used

This project uses:

- Variables
- Data types
- User input
- Type conversion with `int()`
- Arithmetic operators
- Output printing

## How to run

```bash
python student_performance_calculator.py
```
