# Student Utility Toolkit

This project demonstrates Functions, Modules, Scope, and Lambda Functions in Python.

Run the toolkit:

```bash
python -m student_toolkit.main
```

Features:
- Add, display, and update student information
- Academic calculations: total, average, percentage, grade
- Utility operations: highest/lowest marks, sorting, searching
- Lambda functions used for sorting and custom processing
- Scope demonstration showing local vs global variables

Files:
- student_toolkit/student_info.py
- student_toolkit/academic.py
- student_toolkit/utility.py
- student_toolkit/main.py
